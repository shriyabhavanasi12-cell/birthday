A playful, pixel-art-inspired birthday website featuring a virtual cake, colorful candles, and personalized birthday greetings.Just open the page and blow toward your device—watch the candles flicker out in response! Great for birthday greetings, party invites, or just fun surprises.

features:

 1)Personalized birthday greetings — Display a birthday message using a name supplied through the URL.

2) Customizable candle count — Choose between 1 and 30 candles using URL parameters.

3)Random candle colors — Generate candles in different colors.

4)Pixel-inspired design — Uses Pixelify Sans typography and CSS-based visuals.

 languages used : HTML, CSS, and JavaScript 

 how to use 

 
 1. Clone the repository

https://github.com/shriyabhavanasi12-cell/birthday

Replace https://github.com/shriyabhavanasi12-cell/birthday with the URL of your own GitHub repository.

2. Open the project

Open index.html in your browser to view the birthday cake.

3. Customize the birthday greeting

Use URL parameters to personalize the page.

Example:

index.html?name=Shriya&candles=10

name — Sets the birthday person's name.

candles — Sets the number of candles, from 1 to 30.

4. Allow microphone access

Your browser will ask for permission to use the microphone — click Allow.

4. Blow toward your device 🎂

Blow gently toward your laptop or phone’s mic. If detected, the candles will extinguish one by one ✨.
